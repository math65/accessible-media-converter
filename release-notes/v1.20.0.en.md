- **Apply a preset to just one file.** Applying a preset from the file list's right-click menu (**Apply Preset…**) now affects only the selected file(s): it sets that file's output format and encoding settings without changing the global settings or the other files. This makes it easy to convert, say, one file to MP3 and another to FLAC in the same batch. The **Presets…** button still applies a preset to everything at once, as before.
