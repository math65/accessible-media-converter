- **Old AVI files converted to MP4.** With "Copy Stream (Advanced)" enabled for video, old AVI files (DivX 3, for instance) all failed: their video cannot be placed as is inside an MP4, and FFmpeg then refused to write the file. These conversions now succeed: the video is re-encoded automatically whenever the output format cannot hold it without re-encoding. The file list says so explicitly ("Done (re-encoded, copy not possible)"), and merging gets the same safety net. Note: an MKV output does accept these videos as a direct copy.
- Files whose stream really can be copied still are: nothing is re-encoded unnecessarily.
