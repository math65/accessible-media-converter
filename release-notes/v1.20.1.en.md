- **Video conversions that failed on some files of a batch.** After applying "Manage Tracks" or "Choose Audio Track" to several files at once, the files holding fewer tracks than the reference file failed with an FFmpeg error ("Stream map matches no streams"). Tracks that a file does not have are now simply ignored for that file instead of failing its conversion; the other files still get exactly the settings you asked for.
- **More reliable TV recordings.** Broadcast captures (.mpg, .ts, .vob…) sometimes carry a damaged audio track whose parameters FFmpeg cannot read, and the whole file failed to convert. These recordings are now analysed more deeply, and a track that stays unreadable is left out — flagged as such in the track manager — instead of blocking the entire conversion.
- **Clearer cue sheet messages.** A cue sheet with a doubled extension ("Album.cue.cue") now finds its audio file. A cue sheet that references one file per track explains that there is nothing to split instead of showing a generic error — and the exact reason now appears directly in the file list.
- **Usable error reports.** When a conversion fails before FFmpeg even starts, the report sent to support finally contains the application's error message. Such reports used to arrive empty, which made diagnosis impossible.
- Internal fixes: system resources opened for each conversion are now released immediately (this matters on large batches), and the interface was brought in line with the new wxPython version.
