- **Vieux fichiers AVI convertis en MP4.** Avec le mode « Copier le flux (avancé) » activé pour la vidéo, les AVI anciens (DivX 3 par exemple) échouaient tous : leur vidéo ne peut pas être placée telle quelle dans un MP4, et FFmpeg refusait alors d'écrire le fichier. Ces conversions aboutissent désormais : la vidéo est automatiquement réencodée lorsque le format de sortie ne peut pas l'accueillir sans réencodage. La liste des fichiers l'indique clairement (« Terminé (réencodé, copie impossible) »), et la fusion bénéficie du même filet. À noter : une sortie MKV, elle, accepte ces vidéos en copie directe.
- Les fichiers dont le flux peut réellement être copié continuent de l'être : rien n'est réencodé sans nécessité.
