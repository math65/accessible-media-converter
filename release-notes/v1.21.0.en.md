- **New: iPhone ringtones (M4R).** A new output format, "M4R - iPhone Ringtone", turns any song into a ringtone, and from the video tab, the soundtrack of a video too. An iPhone does not accept a ringtone longer than 40 seconds, so the ringtone keeps 40 seconds of the file. The new "Ringtone start (seconds)" setting chooses where it begins: for example 72 to start at 1:12, on the chorus. This setting only appears when a file is longer than 40 seconds; a shorter file is kept whole. M4R files are also accepted as input.
- **Fix: some sample rates made the conversion fail.** The settings offered 96 kHz for every format, but MP3 and WMA cannot go above 48 kHz, and Opus (in MKV) only accepts 48, 24, 16, 12 and 8 kHz. Choosing one of these rates stopped the conversion with an error and no output file. The list now only offers the rates each format supports, and a rate saved earlier that the format refuses is replaced by the nearest one it accepts.
- **Fix: a full disk was reported as an unreadable error code.** When the destination disk ran out of space, the application showed "FFmpeg error (code 4294967268)" and opened the error report form. It now says plainly that there is not enough free space on that disk, in the file list and in the end-of-batch message, without asking you to send a report.
